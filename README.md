# AR Photo Video Scanner

Один локальный сервер на вашем Mac:

- `/admin` — закрытая админка.
- `/scan` — один публичный AR-сканер для всех посетителей.
- фото + видео добавляются из админки;
- MindAR target-база собирается автоматически на вашем Mac;
- открытые сканеры получают SSE-событие и обновляются без ручного F5;
- фото, видео, база и `.mind` находятся локально в `data/`;
- A-Frame и MindAR раздаются с вашего сервера из `node_modules`, поэтому сканер не зависит от CDN.

MindAR 1.2.5 предоставляет `OfflineCompiler` для локальной сборки target-файлов; официальный пример также показывает компиляцию target images и экспорт `.mind`. A-Frame 1.8.0 — актуальный npm-релиз на момент создания проекта. Подробнее: официальные репозитории MindAR/A-Frame. 

## Установка на Mac

```bash
cd "/Users/market/Desktop/ar-photo-video-scanner"
npm install
cp .env.example .env
```

Откройте `.env` и обязательно задайте свой пароль:

```env
ADMIN_USER=admin
ADMIN_PASSWORD=ваш_сильный_пароль
```

Запуск:

```bash
npm start
```

Открыть на Mac:

```text
http://localhost:3000/admin
http://localhost:3000/scan
```

## Работа

В админке добавляете:

```text
Название
Фото для скана
Видео
```

Сервер сам:

```text
сохраняет файлы
→ строит AR targets
→ публикует targets.mind
→ отправляет событие всем сканерам
→ сканеры автоматически перезагружают AR-базу
```

Количество объектов не ограничивается программно. Практический предел будет зависеть от размера и качества изображений, а также от мощности Mac и телефонов.

## HTTPS для посетителей

Для публичного доступа с телефонов используйте бесплатный Cloudflare Tunnel. Для тестирования можно запустить Quick Tunnel:

```bash
cloudflared tunnel --url http://localhost:3000
```

Он даст HTTPS-адрес на `trycloudflare.com`. Для постоянного адреса создайте обычный Cloudflare Tunnel и направьте его на `http://localhost:3000`.

Mac при этом остаётся вашим сервером.
